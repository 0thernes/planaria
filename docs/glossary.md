# Technical Glossary (`v2.4.0`)

This concise glossary covers PLANARIA's core architectural, coding-theoretic, cryptographic, VM, quantum-temporal, and formal-verification terms (synchronized with the A–Z extended glossary in [`GLOSSARY.md`](../GLOSSARY.md)).

- **Anastomosis (Vascular Control-Flow Anastomosis):** Deterministic runtime rerouting in `PVM-32` (`ORGAN_CALL`) where a missing or damaged high-stratum organ (`B1`–`B5`) gracefully falls back down the viability lattice (`S3 -> S2 -> S1 -> S0 -> SafeStub`) with transactional RAM/voice rollback on traps.
- **Byzantine Cell:** A forged `512`-byte cell that passes inner `RS(254, 238)` parity checks (and sync framing) but carries an invalid or rival-lineage Merkle proof intended to poison outer $\mathrm{GF}(2^8)$ Cauchy MDS linear decoding.
- **Cauchy MDS Matrix:** A $k \times n$ matrix over $\mathrm{GF}(2^8)$ (`0x11D`) with entries $C_{i,j} = (x_i \oplus y_j)^{-1}$ for pairwise distinct $x_i, y_j$. Every $k \times k$ submatrix is invertible (Maximum Distance Separable), allowing exact reconstruction from any $k$ surviving shards.
- **CHSH Inequality (Horodecki Criterion):** Bell nonlocality bound $S \le 2$ for local hidden-variable theories and $S \le 2\sqrt{2} \approx 2.8284$ in quantum mechanics; computed exactly in `src/quantum/qengine.js` via eigenvalues of $T^\top T$ for the reduced 2-qubit state.
- **Clean-Room Python 3 Oracle (`reference/planaria_oracle.py`):** Independent zero-dependency Python 3 implementation verifying $\mathrm{GF}(2^8)$, `RS(254,238)`, Cauchy MDS, `PLACEMENT_SCHEDULE`, Depth-8 Merkle proofs, all 4 compiled `.hbin` binaries (768 cells), unaligned mitosis, and 4-qubit CHSH/Mermin invariants.
- **Domain Separation:** Prepending distinct tags (`0x00` for live leaves, `0x01` for internal nodes, `0x02 || "PLN\0"` for empty padding leaves) prior to SHA-256 hashing to prevent second-preimage structural confusion.
- **Equal-Storage Baseline (`RS(192, 48)`):** Flat all-or-nothing MDS control using the identical `98,304`-byte file size and `192`-cell granularity as `.hbin` ($k = 48$, $25\%$ cliff), isolating the survival gain of progressive stratification from raw redundancy overhead.
- **`.hbin` (Holographic Binary):** PLANARIA's headerless `98,304`-byte (`192 × 512` B) self-synchronizing executable format.
- **Interleaved `RS(254, 238)`:** Two byte-interleaved Reed–Solomon codewords per `512`-byte cell, correcting up to $8$ random byte errors per lane or a $16$-byte contiguous burst per cell while strictly rejecting $\ge 9$ errors per lane (17+ byte bursts exceed $t = 8$ in at least one lane).
- **Iterative Backward Flywheel (±512 B Cadence Flywheel):** Decoder recovery mechanism in `src/core/hbin.js` that steps backward and forward in `512`-byte strides from any synchronized cell to recover adjacent cells whose `4`-byte `PLN\xB7` sync header was obliterated.
- **Lineage Root (`lineageRootHex`):** The 128-bit truncated root of the Depth-8 domain-separated SHA-256 Merkle tree committing to all `192` authentic cells of a compiled organism (128-bit second-preimage resistance, 64-bit birthday collision resistance).
- **Mermin Witness ($|M_4|$):** 4-qubit multipartite nonlocality observable with classical local-hidden-variable bound $|M_4| \le 2.0$ and algebraic quantum maximum **$|M_4| = 4.0$** on $\mathrm{GHZ}_4 = (|0000\rangle + |1111\rangle)/\sqrt{2}$.
- **Mitosis (Zero-Overlap Planarian Mitosis):** Splitting a `.hbin` binary into two disjoint byte regions (exact or unaligned prime cut such as `49,177 B`) such that each half independently recovers all 7 bundles and regenerates the bit-exact `98,304`-byte parent binary.
- **Overlap-Eclipse Attack:** Adversarial injection of a bogus `PLN\xB7` sync marker 1–511 bytes before an authentic cell to trick naive `+512` stride scanners into skipping past and eclipsing the real cell; defeated by byte-granular scanning + ±512 B flywheel.
- **Palomar Comparator (`Challenge.lean` / `Solution.lean`):** Lean 4.35.0 verification protocol checking that `Solution.lean` proves every theorem declared in a standalone zero-proof `Challenge.lean` using only axioms within `{propext, Classical.choice, Quot.sound}`, with six kernel checks in CI (Lean default and paranoid, lean4lean, nanoda, con-leche, con-ron) plus a CI negative tampering check.
- **`PLACEMENT_SCHEDULE`:** Exact-integer low-discrepancy ordering `posNum(b, i, n_b) = (14 * i + 2 * b + 1) * (480 / n_b) ∈ (0, 6720)` sorted lexicographically by `(posNum, b, i)`, placing exactly `n_b / 2 >= k_b + 2` cells of every bundle into slots `0..95` and `96..191` with zero midpoint ties at `3360`.
- **`Plang`:** PLANARIA's structured 7-bundle systems programming language compiled to `PVM-32` RISC bytecode.
- **`PVM-32`:** PLANARIA's deterministic 32-bit sandboxed register virtual machine (`4,096`-word `& 0xFFF` RAM, `16,000`-insn default frame budget + proportional blitter fuel, transactional trap rollback, 6-organ anastomosis, Bundle 6 non-executable).
- **Sovereign Bundles (`B0`, `B6`):** The Stem Nucleus (`B0`) and Genome Ledger (`B6`), which are architecturally prohibited from cross-species xenograft replacement.
- **Stratum (`S0`–`S3`):** Progressive protection tier (`S0`: `B0 k=2/24`; `S1`: `B1 k=4/24, B2 k=4/24`; `S2`: `B3 k=8/32, B4 k=6/24`; `S3`: `B5 k=16/40, B6 k=8/24`; total `k=48, n=192`).
- **Xenograft (Cross-Species Chimera):** Transplanting viable non-sovereign organ bundles (`B1`–`B5`) from an authentic donor species into a living amputated host species (`B0` viable) after strict ABI signature matching.
